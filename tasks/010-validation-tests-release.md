# 010. Валидация, ошибки, тесты и релизная проверка

## Этап

Этап 7. Проверка готовности

## Цель

Проверить MVP целиком, закрыть крайние случаи из PRD и подготовить проект к локальному использованию.

## Контекст из PRD

Система должна заменить разрозненную регистрацию заявок единым рабочим местом. Важны корректность связей, понятные ошибки удаления, демоданные и работоспособность всех экранов после первого запуска.

## Scope

- Проверить backend-валидацию обязательных полей.
- Проверить frontend-валидацию ключевых форм.
- Проверить сообщения при запрещённом удалении связанных записей.
- Проверить расчёт просроченных заявок на списке и дашборде.
- Проверить демонстрационные данные на всех экранах.
- Добавить минимальные автоматические тесты или smoke-проверки для API и критических сценариев.
- Обновить инструкции запуска и проверки проекта.
- Провести финальный ручной проход по MVP.

## Out of Scope

- Полноценная e2e-инфраструктура, если она непропорциональна MVP.
- Нагрузочное тестирование.
- Production deployment.

## Requirements

- Все формы должны корректно обрабатывать пустые обязательные поля.
- Ошибки backend не должны отображаться как технический stack trace.
- Демо-данные должны покрывать клиентов, договоры, сотрудников, заявки, работы, графики и отчёты.
- Просроченность должна одинаково считаться в API, списке и дашборде.
- Инструкции запуска должны быть достаточны для локальной проверки.

## Acceptance Criteria

- Приложение запускается с чистой базой и автоматически создаёт демоданные.
- Дашборд, заявки, карточка, справочники и отчёты открываются без ошибок.
- Создание и редактирование заявки проверены вручную.
- Добавление работы в карточке заявки проверено вручную.
- Запрещённое удаление связанной записи показывает понятную причину.
- CSV-экспорт проверен хотя бы для одного отчёта каждого типа.
- Команды тестирования или smoke-проверки описаны и выполняются без ошибок.

## Dependencies

- Все предыдущие задачи.

## Implementation Notes

Если времени на тесты мало, приоритет: API создания заявки, API удаления связанной записи, расчёт просроченных и CSV-экспорт.
