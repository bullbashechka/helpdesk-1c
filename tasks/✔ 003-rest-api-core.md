# 003. REST API для справочников и заявок

## Этап

Этап 2. База данных и серверная основа

## Цель

Реализовать REST API, через который frontend сможет работать со всеми сущностями MVP.

## Контекст из PRD

Frontend обменивается с backend данными в формате JSON. Пользователь управляет клиентами, договорами, сотрудниками и заявками, а статусы и категории выбирает из фиксированных справочников.

## Scope

- Реализовать CRUD endpoints для клиентов.
- Реализовать CRUD endpoints для договоров.
- Реализовать CRUD endpoints для сотрудников.
- Реализовать endpoints чтения для статусов и категорий.
- Реализовать CRUD endpoints для заявок.
- Реализовать endpoints чтения и добавления работ по заявке.
- Поддержать получение заявок с клиентом, договором, категорией, статусом и ответственным сотрудником.
- Поддержать поиск заявок по теме и описанию.
- Поддержать фильтр просроченных заявок.
- Вернуть понятные ошибки валидации и ошибки удаления связанных записей.

## Out of Scope

- Отчёты и CSV-экспорт.
- Графики дашборда на frontend.
- Авторизация и права доступа.

## Requirements

- Все ответы API возвращаются в JSON.
- Поля, обязательные в PRD, валидируются на backend.
- Для новой заявки дата создания проставляется автоматически.
- Описание и дедлайн заявки могут быть пустыми.
- Просроченными считаются заявки с прошедшим дедлайном во всех статусах, кроме «закрыта».
- Статусы и категории нельзя изменять через пользовательские API.

## Acceptance Criteria

- Можно создать, прочитать, обновить и удалить клиента без связанных записей.
- Можно создать, прочитать, обновить и удалить договор без связанных заявок.
- Можно создать, прочитать, обновить и удалить сотрудника без связанных заявок и работ.
- Можно создать, прочитать и обновить заявку со всеми обязательными полями.
- Нельзя создать заявку без договора, категории, статуса, ответственного сотрудника, темы или приоритета.
- Можно добавить работу в карточку заявки.
- API списка заявок возвращает данные, достаточные для таблицы из PRD.
- Ошибка удаления связанной записи содержит понятное сообщение для пользователя.
