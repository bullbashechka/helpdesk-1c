# 008. Справочники клиентов, договоров и сотрудников

## Этап

Этап 5. Справочники

## Цель

Реализовать экраны управления клиентами, договорами и сотрудниками.

## Контекст из PRD

Пользователь должен добавлять, редактировать и удалять клиентов, договоры и сотрудников. Статусы и категории фиксированы и не редактируются через интерфейс.

## Scope

- Реализовать список клиентов.
- Реализовать создание, редактирование и удаление клиента.
- Реализовать список договоров.
- Реализовать создание, редактирование и удаление договора с привязкой к клиенту.
- Реализовать список сотрудников.
- Реализовать создание, редактирование и удаление сотрудника.
- Показывать понятное сообщение, если удаление заблокировано связанными данными.
- Использовать справочники в формах заявок.

## Out of Scope

- CRUD для статусов и категорий.
- Импорт клиентов или договоров из файлов.
- Архивация записей вместо удаления.

## Requirements

- Поля клиента: наименование, БИН/ИИН, контактное лицо, телефон, email, адрес.
- Поля договора: клиент, номер, дата начала, дата окончания, тип сопровождения, тариф.
- Поля сотрудника: ФИО, должность, телефон, email.
- Удаление клиента с договорами должно быть запрещено.
- Удаление договора с заявками должно быть запрещено.
- Удаление сотрудника с заявками или работами должно быть запрещено.
- Статусы и категории доступны только для выбора в заявках.

## Acceptance Criteria

- Клиента можно создать, увидеть в списке и отредактировать.
- Клиента без договоров можно удалить.
- Договор можно создать с выбором клиента, увидеть в списке и отредактировать.
- Договор без заявок можно удалить.
- Сотрудника можно создать, увидеть в списке и отредактировать.
- Сотрудника без связанных заявок и работ можно удалить.
- При запрещённом удалении пользователь видит причину отказа.
- В интерфейсе нет экранов редактирования статусов и категорий.
