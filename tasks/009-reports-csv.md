# 009. Отчёты и CSV-экспорт

## Этап

Этап 6. Отчёты и экспорт

## Цель

Реализовать раздел отчётов: «Заявки за период», «Часы по сотрудникам» и выгрузку результатов в CSV.

## Контекст из PRD

Пользователь формирует два отчёта и может выгрузить любой сформированный отчёт в CSV для дальнейшей обработки.

## Scope

- Реализовать backend endpoints для отчёта «Заявки за период».
- Реализовать backend endpoints для отчёта «Часы по сотрудникам».
- Добавить frontend-раздел отчётов.
- Реализовать выбор диапазона дат для отчёта по заявкам.
- Реализовать период как ограничение для отчёта по часам.
- Показать результаты отчётов в таблицах.
- Реализовать CSV-экспорт каждого сформированного отчёта.

## Out of Scope

- PDF, Excel/XLSX и печатные формы.
- Сохранённые шаблоны отчётов.
- Планировщик автоматической отправки отчётов.

## Requirements

- Отчёт «Заявки за период» выбирает заявки по дате создания.
- Отчёт по заявкам показывает основные данные заявки.
- Отчёт «Часы по сотрудникам» суммирует часы из записей о работах по каждому сотруднику.
- Ограничение периодом для отчёта по часам применяется к датам записей о работах.
- CSV должен содержать заголовки колонок.
- CSV должен корректно экранировать запятые, кавычки и переносы строк.

## Acceptance Criteria

- Пользователь задаёт диапазон дат и получает список заявок, созданных в этом периоде.
- Пользователь формирует отчёт по часам сотрудников без периода.
- Пользователь формирует отчёт по часам сотрудников с периодом.
- Таблицы отчётов показывают данные из БД, а не статичные заглушки.
- Нажатие на экспорт скачивает CSV с текущими результатами отчёта.
- CSV открывается как табличный файл с корректными колонками.

## Implementation Notes

CSV можно формировать на frontend из уже полученных данных или отдавать с backend. Выбрать один подход и применить одинаково к обоим отчётам.
