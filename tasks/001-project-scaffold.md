# 001. Каркас приложения и окружение

## Этап

Этап 1. Каркас проекта

## Цель

Создать базовую структуру проекта для React + Vite frontend, Node.js + Express backend и локального запуска MVP.

## Контекст из PRD

Система должна быть трёхслойной клиент-серверной: React → REST API → SQLite. Авторизация и разделение прав не предусмотрены.

## Scope

- Создать структуру frontend и backend в одном репозитории.
- Настроить `package.json`-скрипты для установки, разработки и запуска.
- Подключить Vite для frontend и Express для backend.
- Настроить обмен JSON между клиентом и сервером.
- Добавить базовые настройки окружения для пути к SQLite-файлу и порта API.
- Подготовить README или краткие команды запуска, если текущий README не содержит их.

## Out of Scope

- Реальная схема БД и демоданные.
- Конкретные экраны приложения.
- Авторизация, роли, внешние интеграции.

## Requirements

- Frontend использует React + Vite.
- Backend использует Node.js + Express.
- API возвращает JSON.
- Локальная разработка должна запускаться предсказуемыми командами.
- Структура проекта не должна предполагать многопользовательскую авторизацию.

## Acceptance Criteria

- Команда установки зависимостей устанавливает frontend и backend зависимости.
- Команда разработки запускает frontend и backend локально.
- Backend имеет health-check endpoint, возвращающий JSON.
- Frontend открывается в браузере и может обратиться к health-check endpoint.
- Ошибки CORS не мешают локальной разработке.

## Dependencies

Нет.
