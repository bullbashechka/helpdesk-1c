# 007. Форма заявки и карточка с историей работ

## Этап

Этап 4. Основной workflow заявок

## Цель

Реализовать создание и редактирование заявок, детальную карточку и добавление записей о выполненных работах.

## Контекст из PRD

Пользователь регистрирует новую заявку, изменяет существующую, меняет статус по мере выполнения и ведёт историю работ прямо из карточки заявки.

## Scope

- Реализовать форму создания заявки.
- Реализовать форму редактирования заявки.
- Реализовать выбор договора с пониманием связанного клиента.
- Реализовать выбор категории, статуса и ответственного сотрудника.
- Автоматически задавать дату создания при сохранении новой заявки.
- Реализовать карточку заявки со всеми данными из PRD.
- Показать историю работ по заявке.
- Добавить форму добавления работы из карточки.
- После добавления работы обновлять историю без ручной перезагрузки страницы.

## Out of Scope

- Редактирование и удаление записей о работах, если это не потребуется для базовой корректности.
- Назначение нескольких ответственных сотрудников напрямую в заявке.
- Комментарии клиентов и вложения файлов.

## Requirements

- Обязательные поля при создании заявки: договор, категория, статус, ответственный сотрудник, тема, приоритет.
- Описание и дедлайн могут быть пустыми.
- При редактировании доступны те же поля, включая статус.
- Карточка показывает клиента и договор, категорию, статус, ответственного, приоритет, тему, описание, дату создания и дедлайн.
- Каждая запись о работе содержит исполнителя, дату, описание и количество часов.
- Количество часов должно быть числом не меньше нуля.

## Acceptance Criteria

- Новая заявка сохраняется при заполнении обязательных полей.
- Попытка сохранить заявку без обязательного поля показывает ошибку.
- Дата создания новой заявки появляется автоматически.
- Существующую заявку можно отредактировать и увидеть изменения в списке и карточке.
- Карточка заявки показывает все поля из PRD.
- Можно добавить запись о работе из карточки.
- Добавленная работа появляется в истории заявки.
